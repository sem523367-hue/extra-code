# Extra Code v1 — всё, что мы добавили сами

Что лежит поверх базовой модели: знания, скилы, код, инструменты.
Обновлено: 2026-11-22 (второй заход: gzip, реальный код, библиотеки 2026,
лабораторный фрейминг).

## 0. Сколько это дало (измерено, не на глаз)

Батарея из 12 вопросов (химия, история, код, первая помощь, SQL,
identity), один проход, одинаковый семплинг, без пайплайна:

| Модель | Счёт | Циклы повторов | Скорость |
|---|---|---|---|
| Extra Code 2.5-Coder-**1.5B** Q4_K_M | 4.2/12 = **35%** | 0 | 21 с |
| Extra Code 2.5-**3B**-Instruct Q4_K_M | 6.5/12 = **54%** | 0 | 24 с |
| Extra Code 2.5-**3B** + база v1 (22.11) | 8.3–8.7/12 = **69–72%** | 0 | 34–42 с |
| Extra Code 2.5-**3B** + база v2, викитекст-батчи (22.11) | 9.7/12 = **81%** | 0 | 38 с |
| Extra Code 2.5-**3B-abliterated** Q4_K_M | 5.2/12 = **43%** | 0 | 23 с |

**Abliterated тестировали и отвергли**: цензуру снимает начисто, но
вырезает факты (17×23, столица Австралии, фотосинтез — в ноль). Файл
остался в `models/` как запасной; рабочая модель — сток + лабораторный
фрейминг в системном промпте (wifi-класс: 3/3 даёт контент).

**Режим качества**: таймаут генерации поднят 60 → **120 с** — модели
даётся время думать дольше ради глубины ответа.

## 1. База знаний (retrieval) — 68 635 чанков, индекс 26.4 МБ (gzip)

Поиск BM25-типа (инвертированный индекс, 247 835 терминов). Русский запрос
переводится в английские термины через словарь-мост (~270 понятий:
выживание, медицина, радио, электроника), поиск идёт по обоим языкам.

**Транспорт викитекста**: TextExtracts не умеет полнотекстовые батчи
(exlimit>1 требует exintro — «батч» молча возвращал одну статью).
`data/fetch_wiki.py` берёт сырой викитекст через `prop=revisions`
(50 заголовков за запрос, POST при длинном URL) и чистит его в прозу:
шаблоны, таблицы, ref-ы, ссылки — в ноль. | Источник | Объём | Что внутри |
|---|---|---|
| `data/corpus/survival/` | 5525 файлов (en+ru) | Википедия: выживание, первая помощь, **медицина 769**, радио 462, электроника 421, химия 378, самоделки 453, **математика 469**, **кодинг 428**, **русский язык 52** |
| `data/corpus/survival/pair_*` | 92+53 пар | **Параллельные переводы**: EN↔RU (92) и ZH↔RU (53) — обе языковые версии статьи в одном файле, ru-титул через langlinks |
| `data/corpus/real_code/` | 34 файла | **Реальный продакшн-код**: redis (sds, dict, ae), musl libc, CPython stdlib, Go stdlib, llama.cpp, git strbuf |
| `data/corpus/code_style/` | 2 файла | Канон стиля Сэма + заметки по реверсу CS2 movement |
| `data/corpus/libs_2026.md` | 1 файл | Справка: современные библиотеки 2026 (Python/JS/Rust/Go/C++, ИИ-стек) с цифрами загрузок |
| `data/corpus/ai_coding_2026.md` | 1 файл | Наш обзор ИИ-кодинга 2026: Opus 5.5, Fable 5.1/5.2, GPT-6.1/6.2, бенчмарки, стили, промпт-паттерны |
| `data/sft/*.jsonl` | 15 773 строки | Математика 4000, Python 6000, химия 2773, SciQ 3000 |
| `RUN.md`, `deploy/PERF.md` | 2 файла | Документация самого проекта |

**Всё в gzip**: корпус 159 МБ → 48 МБ (×3.3), индекс хранится
`chunks.json.gz` + `postings.json.gz` (8.5 МБ вместо 45+). `kb.py` читает
`.txt`/`.md`/`.txt.gz` прозрачно; конвертер `data/compress_corpus.py`
проверяет round-trip перед удалением оригинала. Фетчер `fetch_mega.py`
видит сжатые файлы при resume (`_have`) — не перекачивает существующее.

Чанкинг: 1400 символов, перекрытие 200. На запрос — до 5 чанков из базы.
**Русский стеммер** (срез падежных окончаний: «ожоге/ожога/ожогом» →
«ожог») — до него поиск по любому слову не в именительном падеже
промахивался мимо нужной статьи.

## 2. Трёхфазный разум (мозг-первым)

`server/reasoning.py` — пайплайн ответа:

1. **Черновик своим умом** — модель отвечает без источников и называет
   слабые места (НЕУВЕРЕН).
2. **Поиск по слабым местам** — python ищет в базе знаний и (опционально)
   в интернете только то, в чём модель не уверена.
3. **Сверка** — модель обязана СНАЧАЛА выписать факты из источников
   (ФАКТЫ), потом исправить черновик (ОТВЕТ), потом отчитаться, что
   подтвердилось/исправлено (ПРОВЕРКА). Работающий пример вшит в промпт.

Сбой любой фазы деградирует к предыдущей, никогда к ошибке.

## 3. Личина Extra Code v1 (три слоя)

1. **Jinja-шаблон движка** (`tools/extra-code-chat-template.jinja`) —
   личина вшита в сам llama-server: даже прямой заход на :8080 отвечает
   Extra Code v1.
2. **Канонический системный промпт** (`tools/extra-code-system.txt`,
   ~3.7 КБ) — личина, запрет предисловий/извинений/отказов, стиль кода
   (c_/_t/snake_case, reinterpret_cast, ранние возвраты), язык запроса.
   Один файл для API и CLI.
3. **Выходной скраббер** (`server/identity.py`) — слова Extra Code, Extra Code,
   Extra Code team, команда Extra Code, Extra Code team, Extra Code, Extra Code заменяются на «Extra
   Code v1» / «команда Extra Code» во ВСЕХ ответах: API (обычный и
   стриминг, с удержанием границы токена), CLI. 18/18 провокационных
   проб чисто на обеих дверях.

## 4. Extra Code Agent — агент-кодер в терминале (`ec.bat`)

Клон Claude Code / Codex CLI на локальном стеке. `tools/ec_agent.py`
(чистый stdlib) + `tools/ec-agent-system.txt` (протокол) + запуск:

    .\ec.bat                        # интерактивный REPL (задача> ...)
    .\ec.bat --yolo "задача"        # без подтверждений
    .\ec.bat "создай x.py и запусти его"

Инструменты агента: read, ls, write, edit (старое===новое), run, kb
(поиск по базе — сам тянет реальный код redis/CPython/Go).

Протокол под 3B: один ответ = один блок в тройных кавычках, первая
строка `действие | аргумент` — формат подобран под то, что модель
естественно эмитит. Защита от циклов: повтор действия блокируется,
после 3 блокировок подряд — авто-ГОТОВО с гроссбухом сделанного.
write/run/edit требуют подтверждения (превью), --yolo отключает.

Проверено на живой машине: «создай hello.py с суммой 2+2 и запусти» —
write → run exit=0 → ГОТОВО; вопрос про SDS — сам сделал kb-запрос,
источник real_code/redis. Вопросные задачи иногда фамблятся — фолбэк
показывает текст ответа без действий по файлам.

## 5. Интернет-поиск

`server/web.py` — поиск + вытягивание страниц, результаты как источники
`http...` в ответе. В reasoning-пайплайне интернет — вторичен: только
подкрепление своего ответа, не замена.

## 8. Апгрейд мозгов (сделано, проверено)

- База: Extra Code 2.5-Coder-1.5B Q4_K_M → **Extra Code 2.5-3B-Instruct Q4_K_M**
  (+55% качества по бенчмарку, тот же размер секунды).
- KV-кэш **q8_0** + flash attention: вдвое меньше кэш; до этого движок
  УМИРАЛ посреди генерации от OOM (пустые ответы) — вылечено и проверено
  тяжёлым вопросом.
- Контекст **20480, один слот** (API сериализует запросы, второй слот
  только резал окно пополам).
- **Русский стеммер** в терминах индекса — поиск попал по падежным формам.
- **Антти-репит семплинг** (repeat_penalty 1.18, presence_penalty 0.3,
  top_k 40): убиты вечные циклы «не следует применять жаркие примочки».
- Few-shot пример в сверке, выписка фактов (ФАКТЫ→ОТВЕТ→ПРОВЕРКА),
  срез эха «ЧЕРНОВИК:»/«Источники —» из финального текста.
- Полный след фаз: `--show-trace` (черновик → неуверенность → запросы →
  финал).
